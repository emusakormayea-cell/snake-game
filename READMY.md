# Neon Snake Game

A simple arcade-style snake game built with HTML, CSS, and JavaScript.

## Play the game

Open `index.html` in a browser to start playing.

## Controls

- Arrow keys or `WASD` to move the snake
- Avoid walls and your own tail
- Eat the neon food to increase your score

## Features

- Dark neon theme with a subtle grid background
- Score tracking
- Increasing game speed as you play
- Game-over overlay with a restart button
- Responsive single-file setup with no dependencies

## Project Structure

- `index.html` — all HTML, CSS, and JavaScript for the game in one file

## Run locally

1. Download or clone this repository.
2. Open `index.html` in any modern browser.
3. Click **Start** and begin playing.
